# Sync Batch Data

Projeto Spring Batch para sincronização bidirecional de dados com suporte a múltiplas fontes (H2, MSSQL, Oracle, DB2).

## Tecnologias
- Java 21
- Spring Boot 3.4+
- Spring Batch 5
- RabbitMQ
- Dynamic DataSource Routing
- Grafana + Prometheus

## Como Rodar
```bash
docker-compose up --build
```
